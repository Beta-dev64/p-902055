# Supplied screenshot reference notes

## Full-screen navigation/contact overlay

The supplied navigation reference uses a nearly blank, bright canvas as a high-contrast interruption from the main site. Navigation is not a compact dropdown; it is a full spatial composition. Large route labels sit in a single left column with generous vertical rhythm, while contact details occupy a quieter right column. A small mark anchors the upper-left corner and a simple close control sits in the upper-right. Soft, oversized pale geometric forms provide texture without competing with the labels. The transferable lesson for FuseLabs is to make the menu feel like a designed operating surface: route hierarchy, direct contact, and clear exit affordance should all be visible at once.

## Dark agency hero / studio surface

The supplied dark reference uses a dense, low-contrast repeating texture rather than a gradient. The navigation is a compact floating bar with the brand at left, a centered status phrase, and a menu trigger at right. A separate contact card and a vertical stack of expandable studio sections sit at the right edge. The hero headline is oversized, all-caps, and aligned to a lower-left content block; a supporting paragraph sits on the lower-right. A thin horizontal rule carries small operational metadata across the bottom. The transferable lesson for FuseLabs is to make the engineering identity feel operational: status, categories, contact, and capability should be part of the hero composition, not hidden in later sections.

## FuseLabs translation

The redesign should not copy either reference’s name, copy, logo, or exact visual treatment. FuseLabs will translate the observations into a charcoal engineering canvas with a fine signal-grid texture, a numbered full-screen menu/contact overlay, a compact utility header, a lower-left outcome statement, right-side system metadata, and an operational bottom rail. Space Grotesk remains the type system; amber is reserved for active signal and conversion, while pale bone provides high-contrast type and quiet surfaces.
